# vadasz_denes_vol2

## Introduction

Install packages:

```
npm i
```

In the `electron` folder as well:

```
npm i
```

## How to use

**DEVELOPMENT**

```
npm run dev
```

**PRODUCTION:**

```
npm run build
```

After that, copy the contents of the `out` folder generated by NextJS to the `electron` folder.

( `out` contents -> `electron` )

When you are done, run this command in the `electron` folder:

```
npm run package
```
